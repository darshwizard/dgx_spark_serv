Normal zero-depth decode38.4 has substantial spread (SD12.8; measured20.4,47.6,
47.3tok/s). Preserve individual values and avoid a universal Bolt speed claim.
The capped rates vary in both directions. llama-benchy selects random corpus
start positions using NumPy without a fixed seed in this invocation; normal and
capped prompts are not paired. Speculative acceptance is content-dependent.
Therefore these clock profiles are descriptive measurements, not a causal
throughput-retention or energy-efficiency result. A paired replay is needed.

  using --no-deps. The serving dependency versions are preserved. Dockerfile and
  immutable resulting image ID are included. Build copies the two checked-out
  upstream repos at the commits in spec.json. No new host model service installed.
- Server launch: scripts/bolt_job.py --mode standard --recipe playbook --profile
  normal --run-id UNIQUE. scripts/bolt_standard.py runs upstream CLI commands,
  stored as *-command.json in the output. Stage both scripts as /workspace/code.
- Stage the model/draft as in BOLT-RESULTS.txt. Seed the offline llama-benchy corpus
  cache at /workspace/.cache/llama-benchy/cc6a0b5782734ee3b9069aa3b64cc62c.txt using
  manifest.json's source/hash. Tokenizer is local to avoid network/fallback.
